# @rulebookguard/site

Builds the static site of a [rulebookguard](https://github.com/JuanCJR/rulebookguard#readme) rulebook with Astro Starlight. Install it next to `rulebookguard` to use the `site:generate` and `site:run` commands:

```sh
npm install --save-dev rulebookguard @rulebookguard/site
```

It is kept apart so that `rulebookguard lint` does not download Astro. It requires Node.js 22.23.4 or later.
